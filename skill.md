# Repository Analysis Skill
Analyze historical code changes and development activity. 

##  Triggers 
- "Analyze this repo"
- "Show me historical changes"
- "Audit the dev activity"

## Instructions 
1. Use the `Bash` tool to run `git log --stat`. 
2. Parse the output to identify the most frequently modified files.  
3. Compare current file states using `Read` to identify technical debt. 
4. Provide a summary of the "Development Velocity."

## Tools Required 
- Bash 
- Read 
- Glob
